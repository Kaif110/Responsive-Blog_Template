# iBlog — Responsive Blog Website

A responsive blog homepage made with **HTML, CSS, and vanilla JavaScript**, based on the provided reference screenshots.

## Run it
1. Extract the ZIP.
2. Open `index.html` in your browser, or open the folder in VS Code and use Live Server.
3. Replace the sample article content in `script.js` with your own content.

## Add your images
Put your images in `assets/images/` and use these filenames, or change the paths in `script.js`:
- `hero.jpg` — hero/banner illustration
- `article-1.jpg`
- `article-2.jpg`
- `article-3.jpg`
- `article-4.jpg`
- `article-5.jpg`

If an image file is missing, a visible placeholder shows the expected filename.

## Included functionality
- Responsive desktop, tablet, and mobile layout
- Home / About / Contact navigation
- Mobile navigation menu
- Search articles by title, author, category, year, or excerpt
- Filter articles by year and reset filters
- Contact form front-end validation/feedback
- Article links prefill the contact message with the article title

## Note
The contact form currently works only on the front end. To actually receive messages, connect it to a backend or a form service.
