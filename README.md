# 📝 Responsive Blog Template

A modern and responsive blog template built using **HTML, CSS, and JavaScript**. It features a clean layout, stylish blog cards, and a user-friendly interface designed to provide a smooth reading experience across different screen sizes.

## ✨ Features

- 📱 Fully responsive layout
- 🎨 Clean and modern UI design
- 📰 Blog cards with images and descriptions
- 🧭 Navigation bar
- 🔍 Search functionality (if implemented)
- 📂 Organized content sections
- ⚡ Lightweight and easy to use

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, layouts, and responsive design
- **JavaScript** – Interactive functionality

## 📚 What I Learned

- Responsive web design using CSS media queries
- CSS Flexbox and Grid layouts
- Creating reusable blog card designs
- JavaScript DOM manipulation
- Building clean and user-friendly interfaces

## 🎯 Purpose

This project was created to improve my frontend development skills and practice building responsive website layouts using HTML, CSS, and JavaScript.
